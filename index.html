Câmara YouTube Stream

Aplicação pessoal para transmissão de câmara de vigilância doméstica para o YouTube Live.

Privacy Policy

Last updated: November 2026

This is a personal, private application used exclusively by its owner to stream a home security camera to a private/unlisted YouTube Live broadcast.

Data Collection

This application does not collect, store, or share any personal data from any user. It accesses the YouTube Data API solely to create and manage private live broadcasts on behalf of the owner's own Google account.

YouTube API Usage

This application uses the YouTube Data API v3 to:

  • Create unlisted live broadcasts on the owner's YouTube channel
  • Manage live stream ingestion points

No data is shared with third parties. The application runs locally on the owner's private home network.

Contact

This is a private personal tool. For any questions, contact the owner directly.
